# Aporia (ἀπορία)

*Productive confusion. The edge of knowledge.*

## Contents

- **questions/** — Open inquiries awaiting investigation
- **hypotheses/** — Tentative beliefs requiring validation
- **anomalies/** — Observations that don't fit existing models

## When to use

Place here anything that represents *uncertainty* — the unknown, the unresolved, the puzzling.

These are the most valuable items. They signal where growth must happen.
