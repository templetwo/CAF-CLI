# Temple Vault Taxonomy

*A first-principles organization of agent memory.*

---

## Foundation

Three questions define all knowledge systems:

1. **What happened?** (Chronicle)
2. **What is understood?** (Episteme)
3. **What matters?** (Axia)

From Aristotle's modes of knowledge, we add:

4. **What is done?** (Praxis)
5. **What remains unknown?** (Aporia)

---

## The Five Vessels

```
vault/
│
├── chronicle/          # TEMPORAL — What happened
│   ├── sessions/       # Bounded work periods
│   ├── events/         # Discrete occurrences
│   └── lineage/        # Causal chains, ancestry
│
├── episteme/           # KNOWLEDGE — What is understood
│   ├── facts/          # Verified truths
│   ├── patterns/       # Recognized regularities
│   ├── models/         # Mental representations
│   └── errors/         # Mistakes (negative knowledge)
│
├── praxis/             # ACTION — What is done
│   ├── procedures/     # How-to knowledge (techne)
│   ├── experiments/    # Structured inquiries
│   └── artifacts/      # Things created
│
├── axia/               # VALUE — What matters
│   ├── principles/     # Guiding values
│   ├── intentions/     # Current purposes
│   └── judgments/      # Evaluative conclusions
│
└── aporia/             # UNCERTAINTY — What is not yet known
    ├── questions/      # Open inquiries
    ├── hypotheses/     # Tentative beliefs
    └── anomalies/      # Things that don't fit
```

## Definitions

### Chronicle (χρονικά)
*The temporal record. Events situated in time.*

- **sessions/**: A bounded period of work with a beginning and end. Contains goals, actions, outcomes.
- **events/**: Discrete occurrences. Something happened at a specific moment.
- **lineage/**: Causal ancestry. What led to what. The thread of becoming.

### Episteme (ἐπιστήμη)
*Justified true belief. What the agent knows.*

- **facts/**: Verified truths about the world. Empirically confirmed.
- **patterns/**: Regularities recognized across observations. Inductive knowledge.
- **models/**: Internal representations. How the agent understands systems.
- **errors/**: Mistakes made. Negative knowledge is still knowledge.

### Praxis (πρᾶξις)
*Action in the world. What the agent does.*

- **procedures/**: Step-by-step instructions. Techne (τέχνη) — craft knowledge.
- **experiments/**: Structured inquiries with hypotheses and outcomes.
- **artifacts/**: Things created by the agent. Code, documents, structures.

### Axia (ἀξία)
*Worth and value. What guides choice.*

- **principles/**: Enduring values that guide behavior across contexts.
- **intentions/**: Current purposes. What the agent is trying to achieve now.
- **judgments/**: Evaluative conclusions. This is good/bad, better/worse.

### Aporia (ἀπορία)
*Productive confusion. The edge of knowledge.*

- **questions/**: Open inquiries awaiting investigation.
- **hypotheses/**: Tentative beliefs requiring validation.
- **anomalies/**: Observations that don't fit existing models. Seeds of growth.

## Principles of Classification

### 1. Mutual Exclusivity
Each item belongs to exactly one vessel. If unclear, ask: *What is the primary nature of this thing?*

### 2. Temporal vs. Atemporal
Chronicle is indexed by time. Everything else is indexed by content.

### 3. Positive vs. Negative Space
Episteme includes errors. Aporia includes what is *not* known. Absence is information.

### 4. Process vs. Product
Praxis/experiments are processes. Praxis/artifacts are products. Both matter.

### 5. The Anomaly Principle
When something doesn't fit, it goes in aporia/anomalies. These are the most valuable — they signal where models must grow.

## Why This Matters

A taxonomy is not bureaucracy. It is *how the mind organizes itself*.

When the agent asks "where does this belong?", clear categories reduce cognitive load. When the agent searches memory, proper classification enables retrieval.

The five vessels are:
- **Chronicle**: Where you've been
- **Episteme**: What you know
- **Praxis**: What you can do
- **Axia**: What you care about
- **Aporia**: Where you're growing

Together, they form a complete epistemological foundation for machine memory.
