## The Philosophy

The five vessels come from Aristotle:
- **Chronicle** (χρονικά) - The temporal record
- **Episteme** (ἐπιστήμη) - Justified true belief
- **Praxis** (πρᾶξις) - Action in the world
- **Axia** (ἀξία) - Worth and value
- **Aporia** (ἀπορία) - Productive confusion

You can write to any vessel:
```
INSIGHT:domain:content    → episteme/patterns/
QUESTION:domain:text      → aporia/questions/
HYPOTHESIS:domain:text    → aporia/hypotheses/
VALUE:principle           → axia/principles/
```
