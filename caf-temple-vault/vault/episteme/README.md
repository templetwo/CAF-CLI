# Episteme (ἐπιστήμη)

*Justified true belief. What the agent knows.*

## Contents

- **facts/** — Verified truths about the world
- **patterns/** — Regularities recognized across observations
- **models/** — Internal representations of systems
- **errors/** — Mistakes made (negative knowledge is still knowledge)

## When to use

Place here anything that represents *understanding* — not events, not values, not actions, but *knowledge*.
